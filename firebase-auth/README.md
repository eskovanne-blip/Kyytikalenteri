# Kyytikalenteri-local L1.0.4

Pura haaran ZIP-tiedosto ja avaa juurikansion `index.html` selaimessa. Kalenteri toimii ilman verkkoyhteyttä ja kirjautumista.

- **Avaa CSV** avaa aiemmin tallennetun kalenterin tai version 2.0.35 CSV-varmuuskopion. Aiemmasta varmuuskopiosta luetaan kalenteritiedot.
- **Tallenna CSV** luo kalenteritiedoston. Kun selain tukee suoraa tiedostokirjoitusta, muutokset tallentuvat sen jälkeen automaattisesti avattuun tai luotuun tiedostoon. Avaa tiedosto uudelleen seuraavalla käyttökerralla.
- Jos suora tiedostokirjoitus puuttuu, **Tallenna CSV** lataa uuden tiedoston. Lataa uusin versio ennen sivun sulkemista.
- **Lataa CSV-kopio** tekee erillisen kopion kalenterin senhetkisistä tiedoista.
